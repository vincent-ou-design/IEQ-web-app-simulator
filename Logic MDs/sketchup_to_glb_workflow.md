# SketchUp to `.glb` Export & Integration Guide

This guide explains how to model your custom 3D room in SketchUp, name components for auto-binding, and update your web app with **zero AI token cost**.

---

## Step 1: Component Naming Rules in SketchUp

When modeling in SketchUp, use these exact prefix tags for component names so the JavaScript code in `index.html` automatically recognizes them:

| Architectural Element | SketchUp Component Name Tag | What It Controls in Web App |
| :--- | :--- | :--- |
| **Vision Glazing** | `GLZ_Win` (or `GLZ_Win_VLT45`) | Glass transparency, tint, and daylighting point calculations. |
| **Indoor Planters** | `PLANT_Group` | Plant visibility and biophilic score updates. |
| **Light Fixtures** | `LIGHT_Fixture` | Room illumination intensity and CRI color warmth. |
| **Acoustic Walls** | `WALL_Acoust` | Acoustic wall panel textures and STC score updates. |
| **Ergonomic Furniture**| `DESK_Ergo` | Desk height animations and adaptable layout points. |

*Note: You do NOT need to include height dimensions ($H$) in window component names—the web app automatically detects bounding box heights.*

---

## Step 2: Exporting from SketchUp to `.glb`

1. Open your completed model in SketchUp.
2. Go to **File $\rightarrow$ Export $\rightarrow$ 3D Model**.
3. Select **`GLTF / GLB File (*.glb)`** as the file format.
4. Export options:
   - Check **Export Component Hierarchy**.
   - Check **Preserve Component Names**.
5. Save the file as **`room_model.glb`**.

---

## Step 3: Placing the File in Your Project Folder

Place `room_model.glb` in the exact same folder as your `index.html` file:

```text
my-leed-simulator/
├── index.html          <-- Generated by Antigravity / Codex
└── room_model.glb      <-- Exported directly from SketchUp
```

---

## Step 4: The Zero-Token Revision Workflow

If you want to edit your 3D room later (e.g., add more desks, change room dimensions, or add new windows):

1. Edit your model in SketchUp.
2. Re-export to `room_model.glb` (overwriting the old file).
3. Refresh your web browser (`F5`).

**Result:** Your web application updates instantly with your new 3D geometry! You do **not** need to prompt the AI or re-generate any HTML/JavaScript code.
